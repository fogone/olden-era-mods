# Olden Era mods — project context

Mods for **Heroes of Might and Magic: Olden Era**: data (JSON overlays) and BepInEx plugins.
Machine-specific notes, if any, live in an untracked `CLAUDE.local.md`.

Start with this file, then the tasks: **GitHub Issues** of the repository (`gh issue list --repo fogone/olden-era-mods`). New requests go there (`gh issue create`); close done ones with a link to the commit. Documents are in English. Details:
- `docs/process.md` — the work cycle (build → install → launch → in-game check → log) and debugging techniques;
- `docs/game-internals.md` — what is known about the game's code and data;
- `docs/mods.md` — player guide; `docs/building.md` — building and cutting a release (`release.ps1 -Publish`);
- `docs/hero-data-schema.md` — the hero JSON format;
- `docs/writing-a-mod.md` — writing a mod on the framework, step by step; `docs/catalog.md` — the mod catalog's format and hosting one.
- `install/install.ps1` — the one-line installer for players (finds the game, BepInEx, the mod manager; `-DryRun`, `-Uninstall`), issue #18.

**The repository is public: every change goes through a pull request** (a branch, `gh pr create`), merged once the check passed: `tools/check-public.ps1` looks for anything personal, secrets and game files in what it adds (`docs/building.md`, "Changes to the repository"). Before committing, read the diff for the same; run `.\tools\install-hooks.ps1` once in a checkout.

## Environment (Windows)
- **The game is Xbox/Game Pass by default, not Steam:** `C:\XboxGames\Heroes of Might and Magic- Olden Era\Content`. `C:\Program Files\WindowsApps\HoodedHorse...` is a junction to that folder.
  - Version: `appxmanifest.xml` → `Package.Identity.Version` (on 31.10.2026 — **0.82.7.0**). Unity 6000.0.66f1, IL2CPP, metadata not encrypted.
  - Game data is JSON in `HeroesOldenEra_Data\StreamingAssets\Core.zip`. The game loads **all** `.zip` files from `StreamingAssets`, so extra archives, backups included, must not be put next to it.
- **BepInEx 6.0.0-be.788 (IL2CPP)** is installed in the game folder.
  - Log: `<game>\BepInEx\LogOutput.log`; Unity log: `%USERPROFILE%\AppData\LocalLow\Unfrozen\HeroesOldenEra\Player.log`.
  - Wrappers for the game's code: `<game>\BepInEx\interop\` (`Hex.dll` is the game's code). After a game patch BepInEx regenerates them on the first launch, which takes about a minute.
  - The BepInEx console is disabled (`BepInEx\config\BepInEx.cfg`, `[Logging.Console] Enabled = false`).
- **.NET SDK 10.0.402** is installed per user: `%LOCALAPPDATA%\Microsoft\dotnet\dotnet.exe`, not in PATH.
  - Plugins target `net6.0` and build against `<game>\dotnet\*.dll` (no NuGet, no downloads).
  - Because of this `CompilerAttributes.cs` is needed (`NullableAttribute` stubs).
- Pass a multi-line commit message as a file with a short path, e.g. `$env:TEMP\...`: PowerShell 5.1 mangles here-strings in arguments.

## Working rules
- **MAIN RULE: USE THE GAME'S OWN FUNCTIONS, DO NOT REWRITE ITS LOGIC.** Calculations (damage, danger, flee, join), widget filling (skulls, garrison, tooltips), sprites, fonts and texts are taken from the game: find its method and call it. Write your own implementation only if no game method was found, and say so. First look for how the game itself does it in a similar place (for example, the unit dwelling's skulls for the other guarded buildings).
- **Game names are a generated file per version** (decision 05.11, `docs/game-names.md`, in progress): the searches run at build time over the game files (`tools/game-names`, automatically via `Directory.Build.targets` when the game was updated or the searches changed), the result is `mod-common/shared/GameNames.g.cs` in git, ambiguities are pinned in `GameNames.pins.txt`; code is written on top of it without reflection. A mod built for another game version does not enable (`ModBase`).
- **Readable names for the game's functions.** As soon as it is clear what a game method or property does (an obfuscated property or field like `BhTooltip.cfsf` included), create an alias with a readable name for it: an extension method for a method, an extension property for a property (C# 14, an `extension(T x) { ... }` block; SDK 10 builds it). The alias finds the game member by signature once and logs what it found; the comment says what it is in the game and its name on the current version, e.g. `umo` on 0.82.7. At first the alias lives in the code of the mod that needed it. Later aliases are moved in bulk to `mod-common/shared/Game*.cs` (class `Game`), and all mods switch to the shared ones. Obfuscated names and signature searches in place are not used in mod code. Aliases are written via `Lookup`/`Members` (`mod-common/shared/Members.cs`), hooks via `PatchEach`; repeated reflection goes to shared code, not copied.
- **Installing into the game.** A plugin may be installed into `plugins` only while the game is closed: `build.ps1 -Install` refuses if the `HeroesOldenEra` process is alive. If the game is open, ask for it to be closed. Never kill the process without consent. Plugins built on `ModBase` in `devplugins` update while the game is open: `build.ps1 -Dev`, see `docs/process.md` "Hot reload".
- **Launching the game:** `Start-Process "shell:AppsFolder\HoodedHorse.HeroesofMightandMagicOldenEra_znaey1dw2bdpr!Game"`, then wait for `Chainloader startup complete` in the log.
- **In-game checks (hovering, approaching squads, battles) are done by a human player.** Ask for exactly what is needed for the check: which squad, with which hero, what to do. For repeats, suggest saving.
- **The game's code is obfuscated, names change with every patch.** Search for methods by signatures and readable types (`DataSquad`, `HeroStat`, the UI `Bh*` classes). Names like `fcr.bkes` may be relied on only when debugging. Identical functions are sometimes merged at one address (cannot be detoured twice) and sometimes duplicated as clones at different addresses.
- **All strings visible in the game go through localization:** a key in the plugin's `lang/russian.json` and `lang/english.json`, in code `Texts.Get(key)`. Not literals, not in the config. The game's font has no "≈".
- **Do not use `XrefScanner` (Il2CppInterop)** on arbitrary methods: it crashed the game twice. Safe alternatives are described in `docs/process.md`.
- **Hidden numbers must not be exposed** (exact counts, Diplomacy points, the strength ratio). Such things are off by default and enabled only by a config option.
- **Do not present guesses as facts.** If a conclusion has not been verified in the game, say so.
